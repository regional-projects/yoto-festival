【GitHub Pagesで公開する手順】
1. GitHubで新しいリポジトリを作成します。
2. この3ファイルをリポジトリ直下へアップロードします。
3. Settings → Pages を開きます。
4. Deploy from a branch を選択します。
5. Branch を main、フォルダを /(root) にして Save します。
6. 公開されたURLをQRコード化してください。

※ index.html と2枚の画像は同じ階層に置いてください。
